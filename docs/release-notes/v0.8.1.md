**iOS styles and a fix for update checks.**

- **Two iOS styles** (Settings → Style): **iOS 6** — a glossy navigation bar, rounded white groups, shiny buttons, blue switches; **iOS 7** — flat white, big light headers, everything you can press in the tint color, green switches.
- Fixed: *Check for updates* could fail with "403" when GitHub's API limit for your address was used up. MacPilot now reads the latest version from the release page, which has no such limit.

---

**Стили iOS и исправление проверки обновлений.**

- **Два стиля iOS** («Настройки → Стиль»): **iOS 6** — глянцевая панель навигации, скруглённые белые группы, блестящие кнопки, синие переключатели; **iOS 7** — плоский белый, крупные светлые заголовки, всё нажимаемое в цвете акцента, зелёные переключатели.
- Исправлено: «Проверить обновления» могла выдавать «403», когда для твоего адреса исчерпан лимит GitHub API. Теперь MacPilot узнаёт последнюю версию со страницы релиза, где такого лимита нет.

**First launch / Первый запуск:** the release is not notarized — on macOS 15+ open **System Settings → Privacy & Security → Open Anyway** / релиз не нотаризован — на macOS 15+ открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. After an in-app update macOS may ask for permissions again / после обновления из приложения macOS может заново спросить разрешения.
