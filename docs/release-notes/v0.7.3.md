**Page headers stay put.**

- On Disk and Apps the tabs no longer jump when you switch between sections with and without the side panel.
- The Classic style wraps its header in a narrow window too.

---

**Шапки страниц не прыгают.**

- На «Диске» и в «Приложениях» вкладки больше не сдвигаются при переключении между разделами с боковой панелью и без неё.
- В классическом стиле шапка тоже переносится в узком окне.

**First launch / Первый запуск:** the release is not notarized — on macOS 15+ open **System Settings → Privacy & Security → Open Anyway** / релиз не нотаризован — на macOS 15+ открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.
