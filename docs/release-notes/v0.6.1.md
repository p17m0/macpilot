**A clearer menu bar item.**

- A gauge icon next to the numbers, tinted for light and dark menu bars.
- Labeled values: **CPU 23% · RAM 81%** instead of bare percentages.
- Hovering shows "MacPilot — CPU and memory use", so it is clear whose item it is.

**Понятный значок в строке меню.**

- Иконка-спидометр рядом с цифрами, сама подстраивается под светлую и тёмную строку меню.
- Подписанные значения: **ЦП 23% · ОЗУ 81%** вместо голых процентов.
- При наведении — подсказка «MacPilot — загрузка процессора и памяти», чтобы было ясно, чей это значок.
