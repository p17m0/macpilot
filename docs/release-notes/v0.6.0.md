**A design pass after the Macintosh classics.**

- **Clearer type:** real San Francisco weights — bold page titles, semibold headings and names.
- **Every page starts the same way:** title, its sections next to it, its actions on the right; more room on a 4-point grid.
- **Color only where something needs attention:** normal values in plain text, yellow and red for real problems.
- **Startup** shows names for people ("MacKeeper — Reminder") with app icons; **Settings** in grouped boxes like System Settings.
- **Disk → Summary:** pointing at a part of the bar highlights its line; what MacPilot cannot see is hatched.
- New sidebar icons; Cleanup cards show the app they belong to.

Also includes everything from 0.5.5: privacy first, "Don't scan" folders, settings in tabs and a much better search for leftovers of removed apps.

**Дизайн по заветам классического Macintosh.**

- **Чётче текст:** настоящие начертания San Francisco — жирные заголовки страниц, полужирные разделы и имена.
- **Все страницы устроены одинаково:** заголовок, рядом его разделы, справа действия; больше воздуха по сетке в 4 пункта.
- **Цвет — только там, где нужно внимание:** обычные значения обычным текстом, жёлтый и красный — для настоящих проблем.
- **«Автозагрузка»** показывает понятные имена («MacKeeper — Reminder») с иконками приложений; **«Настройки»** сгруппированы, как в Системных настройках.
- **«Диск → Сводка»:** при наведении на часть полосы подсвечивается её строка; то, что MacPilot не видит, заштриховано.
- Новые иконки в боковой панели; карточки «Очистки» показывают, к какому приложению относятся.

Плюс всё из 0.5.5: сначала конфиденциальность, папки «Не сканировать», настройки по вкладкам и гораздо более полный поиск хвостов удалённых приложений.

**First launch / Первый запуск:** the release is not notarized — on macOS 15+ open **System Settings → Privacy & Security → Open Anyway** / релиз не нотаризован — на macOS 15+ открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.
