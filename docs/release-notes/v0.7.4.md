**Cleanup in one click.**

- System junk is one list instead of a wall of cards; the safe places are ticked from the start.
- *Clean selected* moves them all to the Trash after a single confirmation.
- The Trash with *Empty Trash…* stays in sight at the top.
- A click on a row ticks it; the right-click menu cleans one place, opens it or shows it in Finder.

---

**Очистка в один клик.**

- Системный мусор — один список вместо стены карточек; безопасные места отмечены сразу.
- «Очистить выбранное» отправляет их все в Корзину после одного подтверждения.
- Корзина с кнопкой «Очистить Корзину…» всегда на виду вверху.
- Клик по строке отмечает её; в меню по правому клику — очистить одно место, открыть его или показать в Finder.

**First launch / Первый запуск:** the release is not notarized — on macOS 15+ open **System Settings → Privacy & Security → Open Anyway** / релиз не нотаризован — на macOS 15+ открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.
