**App updates, old installers, snapshots.**

- **Apps → Updates**: *Check now* asks the App Store, Homebrew and the apps' own update feeds, and lists the apps with a newer version. Nothing is asked until you press the button.
- **Cleanup → Old installers**: .dmg, .pkg, .xip and .iso files lying in Downloads for more than a month.
- **Disk → Summary**: local Time Machine snapshots with a button to delete them, and how much space macOS can free by itself.
- **Cleanup on a schedule** shows what it would take right now, with *Run now…*.
- Fixed: in a narrow window the buttons of the Disk page covered its tabs.

---

**Обновления приложений, старые установщики, снимки.**

- **Приложения → Обновления**: «Проверить сейчас» спрашивает App Store, Homebrew и ленты обновлений самих приложений и показывает, у каких есть новая версия. Без нажатия кнопки ничего не запрашивается.
- **Очистка → Старые установщики**: файлы .dmg, .pkg, .xip и .iso, лежащие в «Загрузках» больше месяца.
- **Диск → Сводка**: локальные снимки Time Machine с кнопкой удаления и сколько места macOS может освободить сама.
- **Очистка по расписанию** показывает, что убрала бы прямо сейчас, и умеет «Запустить сейчас…».
- Исправлено: в узком окне кнопки страницы «Диск» наезжали на её вкладки.

**First launch / Первый запуск:** the release is not notarized — on macOS 15+ open **System Settings → Privacy & Security → Open Anyway** / релиз не нотаризован — на macOS 15+ открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. After an in-app update macOS may ask for permissions again / после обновления из приложения macOS может заново спросить разрешения.
