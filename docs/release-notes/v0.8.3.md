**Lighter in the menu bar, and fixes.**

- With the window closed MacPilot now uses about 1% CPU instead of 3–7%: monitors slow down while hidden and catch up within a quarter of a second when the window opens.
- Battery temperature works again on macOS 27 (it showed 0.0 °C).
- Homebrew: `brew install --cask p17m0/tap/macpilot` — the cask is attached to every release.
- Disk → Summary no longer starts with a nearly empty card.
- Windows 98: all buttons have the 3D bevel.
- New README screenshots and a picture of all the styles.

**First launch / Первый запуск:** the release is not notarized — on macOS 15+ open **System Settings → Privacy & Security → Open Anyway** / релиз не нотаризован — на macOS 15+ открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. After an in-app update macOS may ask for permissions again / после обновления из приложения macOS может заново спросить разрешения.
