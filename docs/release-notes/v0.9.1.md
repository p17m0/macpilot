**Menu bar.**

- Choose what the menu bar shows next to the icon: CPU, memory, free space, network, temperature, battery — or just the icon (Settings → General → Next to the icon). The digits keep one width, so the item no longer twitches.
- The menu lists the three busiest apps, each with Quit (like ⌘Q) and Show in MacPilot. Parts of macOS are never offered.
- Disk opens on the Map.

---

**Строка меню.**

- Выбирай, что показывать рядом со значком: CPU, память, свободное место, сеть, температуру, батарею — или только значок (Настройки → Основные → Рядом со значком). Цифры одной ширины, значок больше не дёргается.
- В меню — три самых нагружающих приложения, у каждого «Закрыть» (как ⌘Q) и «Показать в MacPilot». Части macOS не предлагаются.
- «Диск» открывается на «Карте».

**First launch / Первый запуск:** the release is not notarized — on macOS 15+ open **System Settings → Privacy & Security → Open Anyway** / релиз не нотаризован — на macOS 15+ открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. After an in-app update macOS may ask for permissions again / после обновления из приложения macOS может заново спросить разрешения.
