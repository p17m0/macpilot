**Themes, retro styles and a new icon.**

- **Color themes**: Settings → Colors has ten palettes for the standard look — MacPilot, Graphite, Ocean, Forest, Sunset, Rose, Nord, Dracula, Solarized and Midnight — each in light and dark.
- **Retro styles** (Settings → Style): Windows 98, Windows XP, Nintendo, Game Boy, PlayStation and PlayStation 2, each with its own colors, typeface, title bar, buttons and switches.
- **The Macintosh style, closer to the original**: Geneva for text, a close box in the title bar, the thick-outlined default button, real 1-bit dither in meters.
- **New icon**: a pixel-art Macintosh in aviator goggles — the pilot of your Mac.

---

**Темы, ретро-стили и новая иконка.**

- **Цветовые темы**: в «Настройки → Цвета» десять палитр для стандартного вида — MacPilot, Графит, Океан, Лес, Закат, Роза, Nord, Dracula, Solarized и Полночь — каждая в светлом и тёмном варианте.
- **Ретро-стили** («Настройки → Стиль»): Windows 98, Windows XP, Nintendo, Game Boy, PlayStation и PlayStation 2 — у каждого свои цвета, шрифт, заголовок окна, кнопки и переключатели.
- **Стиль Macintosh стал ближе к оригиналу**: текст в Geneva, квадратик закрытия в заголовке, кнопка по умолчанию с толстой обводкой, настоящий чёрно-белый узор в шкалах.
- **Новая иконка**: пиксельный Macintosh в лётных очках — пилот твоего Mac.

**First launch / Первый запуск:** the release is not notarized — on macOS 15+ open **System Settings → Privacy & Security → Open Anyway** / релиз не нотаризован — на macOS 15+ открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. After an in-app update macOS may ask for permissions again / после обновления из приложения macOS может заново спросить разрешения.
